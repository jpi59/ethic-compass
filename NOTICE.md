## Name review

On 2026-09-10, a public web search found an older Android application named
“Ethic Compass BDO”, associated with WopDigital/BDO. The project owner chose
to retain the name “Ethic Compass” despite that result. This is not a trademark
clearance and the project must not claim exclusive rights, affiliation with BDO
or WopDigital, or legal availability of the name. A jurisdiction-specific
review is still required before public release if the name presents material
